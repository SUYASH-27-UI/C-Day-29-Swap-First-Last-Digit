# C Day 29 - Swap First and Last Digit

This program swaps the first and last digits of a number.

## Example

Input:
12345

Output:
Original number = 12345
After swapping = 52341

## Concepts Used

- while loop
- for loop
- Modulus Operator (%)
- Division (/)
- First Digit
- Last Digit
- Number Manipulation
